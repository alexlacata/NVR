Acceder depuis un telephone

Scannez ce code avec l'appareil photo du telephone pour ouvrir l'interface NVR (le telephone doit etre sur le meme reseau, ou connecte au meme VPN).

Mon compte

Sessions actives

Les appareils/navigateurs actuellement connectes avec votre compte. Revoquer une session en deconnecte l'appareil correspondant immediatement, sans changer votre mot de passe.

Double authentification (2FA)

Protege votre compte avec un code a usage unique genere par une application d'authentification (Google Authenticator, Authy, 2FAS, ...), en plus du mot de passe.

Scannez ce code (ou saisissez la cle manuellement) dans votre application, puis entrez le code genere pour confirmer :

Notez ces codes de secours maintenant - ils ne seront plus jamais affiches. Chacun permet de se connecter une seule fois si vous perdez l'acces a votre application d'authentification.

        permissions precises (gerer les cameras, piloter le PTZ, supprimer ou
        telecharger des enregistrements, gerer les parametres serveur) sans devenir
        administrateur - seul un administrateur peut gerer les comptes.

Notifications

    

      

        Recevez une alerte quand une camera detecte un mouvement, quand une camera
        passe hors ligne (ou revient), ou quand l'espace disque devient critique -
        par webhook (n'importe quelle URL acceptant un POST JSON : Discord, Slack,
        Home Assistant, ntfy, IFTTT...) et/ou par e-mail.

Routeur

    

      

        Identifiants de connexion a l'interface d'administration de votre routeur -
        utilises uniquement pour le lien d'acces rapide "Routeur" sur le tableau de
        bord (voir aussi les identifiants "Interface web" de chaque camera, sur sa
        propre page). Le NVR ne se connecte jamais lui-meme au routeur : ces
        identifiants ne servent qu'a pre-remplir ce raccourci.
      

      

        

          

          

        

        

        
Le lien "Routeur" du tableau de bord devine l'adresse du routeur
          (le ".1" du reseau de chaque camera) - laissez le champ ci-dessous vide pour
          garder cette deduction automatique, ou indiquez l'adresse exacte si elle est
          fausse pour votre reseau (routeur en ".254", VLAN...).

        

          

        

        
Acces SSH (optionnel, si votre routeur en expose un) : construit un lien
          ssh:// et un bouton pour copier la commande - aucun mot de passe n'est demande ni stocke,
          vous le saisissez vous-meme dans votre terminal.

        

          

          

        

        

        

      

    


    
Sauvegarde

    

      
Chargement...

      

        Copie les enregistrements (pas les vignettes/HLS, ephemeres) vers un second
        emplacement - un NAS monte, un second disque. Se configure via la variable
        d'environnement NVR_BACKUP_DIR (chemin de dossier), pas depuis
        cette page - redemarrez le serveur apres l'avoir renseignee.
